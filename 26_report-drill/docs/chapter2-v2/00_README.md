第1面は「調べ方」のチュートリアル。第2面は「何を調べるか・いつ報告するか」を体験させる。**見積もりの根拠を説明するため、業務目的→修正範囲を確認する**ことを導入独白で明示する。
既存のUI（カンバン、調査.xlsx、Slack風チャット、Meets）を再利用し、採点や攻略の新UIは増やさない。

## 重要: 現状の実装制約
添付版の `scripts/build-content.mjs` は `01_watermark` を固定読込し、`src/data/content.mjs` に単一の `scenario` / `problem` を出力する。第2面のMarkdownは現状、草案・取込対象外。
そのため **第2面のMarkdownだけを追加してもプレイ可能にはならない**。ケース別ビルド・起動・保存の拡張が必要。
既存の第1面は壊さず、まず第2面を選択して単独起動できる状態を目標にする。

## 実装の順番
1. 第2面の事実と報告成立条件をデータ化
2. ケース切替とケース別保存
