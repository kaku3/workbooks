0. 最初のインストカード
カンバン表示後、タスク開始の操作ガイドより前に、全体の目的と流れを伝えるカードを1枚表示する。

> **調べて、手がかりを集めて、報告しよう**
>
> カンバンのタスクから、依頼への回答に必要そうなものを選んで調査しましょう。
>
> 説明に必要な手がかりが揃ったと思ったら、報告タブへ。Web会議で手がかりを3枚選び、依頼主に報告します。
>
> すべてのタスクをこなす必要はありません。
>
> **［了解した］**

画面全体を黒フェードし、カードを中央に表示する。カード表示中は時計を止め、背景の操作を制限する。ボタンはカード下部の横中央に配置し、「了解した」を押すと、タスク開始の操作ガイドへ進む。表示履歴は既存ガイドと同じく全章共通で保存し、初回のみ表示する。カード表示中に再読み込みした場合は再開し、確認後は再表示しない。

1. タスク開始
タスクをドラッグして「作業中」にドロップするとタスクを開始する。

2. 手がかり入手
タスクの内容により手がかりを入手することがある。
報告に必要な手がかりが３枚手に入ったと思ったら、報告タブを選択して報告する。

3. タスク完了
タスクをドラッグして「完了」にドロップするとタスクを完了する。
未着手や作業中に戻すこともできる。

3-1. チャットと履歴
調査や報告の記録は、チャット欄のchatbotが投稿する。投稿をクリックすると、そのときの会話ログを開いて読み返せる。もう一度クリックすると閉じる。
最初のタスクを実行し、完了へ移動した後に、履歴の開き方を一度だけ案内する。PCでは直近のchatbotの投稿を強調し、スマートフォンでは「#pj-marunage」でチャット欄を開いてから同じ投稿を案内する。会話ログを開くとガイドを終了する。手がかりを入手しないタスクでも、会話の履歴があれば案内する。
ガイド中は時計を止め、対象外の操作を制限する。履歴はスクロールして確認でき、本文・話者名・強調文字は明るいログ背景に合う濃い色で表示する。

4. 報告
4-1. 報告タブ
報告タブを選択して報告タブを開く。

4-2. 会議に参加
会議に参加するボタンを押して会議に参加する。

4-3. 画面を共有
画面を共有ボタンを押して報告用画面を共有する。
カードを３枚選択して報告するボタンで報告する。
報告内容が依頼主に伝われば、回答完了だ。

4-4. 報告が伝わらなかったとき
不十分な報告への会話が終わり、報告画面に戻ったときに、「調査カンバン - Backlog」へ戻る操作を初回のみ案内する。会話中や、報告が成立した場合、時間切れで終了する場合には出さない。
調査カンバンのタブを強調し、四角い枠が集まるエフェクトを表示する。タブを押して戻るとガイドを終了する。相手の反応から調査や説明を見直し、手がかりを組み替えて再報告できることを伝える。正解のタスクやカードは指定しない。
ガイド中は時計を止め、再読み込み後も続きから案内する。報告画面で再読み込みした場合は、会議の再参加よりもカンバンへ戻る案内を優先する。カンバンへの移動自体で時間を消費したり、手がかりや調査済みの情報を消したりしない。

## 表示・操作の仕様

ガイドは各項目について、未表示で初めて条件を満たした時に表示する。会話、チケット配置、手がかり入手の演出中は待ち、対象が表示されて操作できるようになってから出す。同時に条件を満たす場合は、以下の表の順で一つずつ表示する。調査の順番や手がかりの正解は指定しない。

| 項目 | 表示条件 | 終了条件 |
|---|---|---|
| 最初のインストカード | 導入・チケット配置の演出が終わり、カンバンが表示される | 「了解した」を押す |
| タスク開始 | 導入・チケット配置後、開始できる未着手タスクがある | 任意のタスクを作業中へ移動 |
| 手がかり入手 | 初めて手がかりを入手し、会話・入手演出が終了 | 説明の「確認した」を押す |
| タスク完了 | 実行済みのタスクが作業中にあり、盤面へ戻る | 実行済みのタスクを完了へ移動 |
| チャットと履歴 | タスク実行後、完了への移動ガイドが終わり、会話の履歴がある | chatbotの投稿をクリックして会話ログを開く。スマートフォンでは先にチャット欄を開く |
| 報告タブ | 手がかりが3枚以上ある | 報告タブを開く |
| 会議参加 | 会議の待機画面を開く | 会議に参加する |
| 画面共有 | 会議に参加し、依頼の説明表示が終了 | 画面共有をオンにする |
| カード選択 | 画面共有中、手がかりが3枚以上あり、選択が3枚未満 | 自分で選んだ3枚を配置 |
| 報告実行 | 画面共有中、3枚を選択済み | 報告する |
| 調査カンバンへ戻る | 不十分な報告の会話が終了して報告画面へ戻る。再読み込み時は会議参加・共有より優先 | 「調査カンバン - Backlog」を押す |

### 黒フェードと操作制限

- 操作対象以外を半透明の黒で覆い、対象を枠で強調する。移動・スクロール・画面サイズの変更に合わせて位置を追従する。
- 「操作ガイド」のラベルは、説明ウィンドウの左上の枠線に重ねて左肩に乗せる。長い説明は本文部分をスクロールさせ、ラベルが切れないようにする。
- 操作対象の周囲から四角い枠が集まるエフェクトを繰り返し表示し、次に操作する場所を示す。ドラッグ時は移動元と移動先の両方に表示する。エフェクトは操作を妨げず、対象の位置・サイズに追従する。操作対象のない最初のインストカードには表示しない。
- 「動きを減らす」設定やブラウザの視差効果軽減設定が有効な場合は、集まるエフェクトを止め、静止した強調枠だけを表示する。
- ガイド中は対象外のクリック、ドラッグ、キーボード操作を遮断する。背景クリックやEscapeでは閉じず、指定の操作の成功を確認して終了する。
- ドラッグの案内では、移動元のタスクと移動先の列の両方を明るくする。対象のタスクはプレイヤーが選べる。完了の案内は実行済みタスクだけを対象にする。
- キーボードではTabで対象へ移動し、Alt＋左右キーでもタスクを移動できる。手がかりはドラッグとクリックのどちらでも選べる。
- タッチ操作でもガイド対象のタスクを移動できる。ドラッグ中に盤面の左右端へ近づけると横スクロールする。
- 手がかり入手は説明のため「確認した」で閉じる。ここでは報告タブへの移動を強制しない。
- ガイド中はゲーム内時計を止める。タスク実行・報告自体に必要なゲーム内時間は通常どおり消費する。
- 手がかり3枚は報告操作を試せる枚数であり、正解を保証する条件ではない。自動でカードを選んだり、組み合わせを教えたりしない。

### 一度だけの表示と保存

- 表示履歴は全章共通で、このブラウザのlocalStorageへガイドIDごとに保存する。
- 表示を開始した時点で表示済みとし、操作終了までは進行中として別に保存する。再描画で重複表示せず、再読み込み後も条件が合えば進行中のガイドを再開する。
- 再読み込み後に対象の画面が異なる場合は待機し、再びその操作ができる時に再開する。完了済みのガイドは再表示しない。
- 章変更、翌日、はじめからの再挑戦では履歴を維持する。「すべての記録を消す」で共通のガイド履歴も削除する。
- 保存が使えない環境でも、ページを開いている間はメモリ上で履歴を維持する。

### 画面共有

会議の説明終了後に自動で画面共有する処理は廃止する。ガイドを表示済みの場合も、共有ボタンを押すまで共有しない。共有をオフにした場合は、再びオンにしてから報告する。報告会話の途中から保存を再開する場合は、その会話を継続できる表示を復元する。
