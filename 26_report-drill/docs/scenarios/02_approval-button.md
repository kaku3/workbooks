# 第2面：承認画面へのボタン追加（草案）

案件ID候補：`approval-button`。題材・台詞ともに未確定。問題は [対応する問題草案](../problems/02_approval-button.md)。

## 導入案

佐伯「経理から、承認画面にボタンを一個追加してほしいって言われているんです」

主人公「何をするボタンですか？」

佐伯「差し戻すボタンです。一個増やすだけなら、すぐできますよね？」

## 調査で出会う会話案

佐伯「経理では、間違ったところを申請者に直してもらいたいそうです。今の却下だと最初から入れ直しなので、問い合わせが来ているんですが」

真壁「ボタンを押した後、誰が続きをやる？」

## 不十分な報告への反応案

佐伯「ボタンが出るのは分かりました。押した後、誰が直せるんですか？」

## 結末案

佐伯「修正して出し直せるようになる、と経理に説明します。その範囲の費用と日程をお願いしますね」

主人公（心の声）「……ボタン一個の話ではなかった。」

## 正式化前に決めること

差戻しと却下の業務上の違い、権限、再申請後の扱いを問題側で確定する。真壁の投稿・対応予定・時間切れ会話は案件専用に作る。
