# 第4面：締め処理の自動化（草案）

案件ID候補：`closing-automation`。未確定。[問題草案](../problems/04_closing-automation.md)。

## 導入案

佐伯「月末の締め作業で、担当者が夜中まで待っているそうなんです。時間になったら自動で押すようにできませんか？」

主人公「押していいかどうかは、誰が判断しているんですか？」

佐伯「……担当者です。そこも一緒にできると思っていたんですが」

## 調査で出会う会話案

佐伯「担当者に聞いたら、全部そろったか確認してから押しているそうです。月によって時刻も違うと。……毎月同じじゃないんですね」

真壁「時刻が来たことと、締めていいことは同じか？」

## 不十分な報告への反応案

佐伯「毎月動くのは分かりました。確認が終わっていない月も、動いてしまうんですか？」

## 結末案

佐伯「自動にできる範囲を担当者に説明します。夜中まで待たずに済む方法が欲しいので、その範囲で見積もってください」

## 正式化前に決めること

実行時刻と業務成立条件を分ける。完全自動化の可否を先に決めず、問題で与える事実から報告できるようにする。
