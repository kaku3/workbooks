# 折原

## 基本設定

| 項目 | 設定 |
|---|---|
| 表示名 | 営業・折原 |
| 元シナリオの話者ID | `sales` |
| 所属 | 自社側。株式会社コウカンゲン |
| 立場 | 案件の獲得や客先への紹介、追加依頼の受注をする営業 |
| 当面の望み | 案件を取り、話を前へ進めること |

## 原稿から読み取れる人物像

善意で動いているのに、何かが根本的におかしい。相手の要望を「便利そう」「お金がもらえる」と前向きに受け取り、技術上の難しさや業務上の制約を詰める前に約束してくる。

未経験者を「経験5年」と紹介する。交通費の申請経験を経費精算システムの経験として扱い、パスワード画面を2回出すことを二段階認証だと理解する。本人の中では話がつながっている。

常に勢いよく話すだけではない。問い合わせが止まらず総点検を求められると長く黙り、真壁の確認が終わると「まったく問題ない」と乗ってくる。契約更新にも敏感。

## 話し方と反応

- 明るい丁寧語。「お話ししておきました！」「受注してきました！」と、すでに決まったこととして伝える。
- 「10万円で！」「10万円もらえるし！」のように、受注できたことを強調する。
- 「パパっとつくっちゃってください！」と、作業の重さを軽く表現する。
- 問題のある挙動にも、便利さや働ける時間が増えるという解釈をつける。
- 都合が悪い場面では沈黙も使う。毎回同じ勢いの台詞にしない。

## 他の人物との関係

- 主人公：期待して現場に送り出す相手。その期待と紹介内容が実力を先回りする。
- 真壁：受注した仕事を形にしてもらう技術側の相手。真壁の対応を前提に話を進めがち。
- 佐伯：発注側の窓口。相手の「便利にしたい」を、実現方法まで理解したつもりで受け取る。
- 三田：業務上の制約を説明してくる相手。三田の懸念より、部長の依頼や受注額を優先してしまう。

## 報告ドリルでの会話方針

見積もり前の約束、説明を聞いたつもりの取り次ぎ、依頼の軽い言い換えによって、調査が必要になるきっかけを作れる。

ただし、実際に確認できた事実や技術的な可否を決める役にはしない。折原の説明を受けた主人公が、元の要望や条件を確認し直す余地を残す。善意という設定は保ちつつ、発言の結果として起きる負担も描く。

## 部屋の特徴（Web会議の背景）

株式会社コウカンゲンの営業用打ち合わせスペース。外向きには明るく整っているが、次の商談へすぐ移れる実用的な部屋にする。

- 壁・家具：白い壁、ガラスの間仕切り、小さな丸テーブル。奥に商談資料を置く浅い棚。
- 小物：無地のパンフレット立て、閉じた営業鞄、付箋の付いた手帳。資料は手に取りやすい位置にまとまっている。
- 色・光：白と明るいベージュ、控えめな青の差し色。室内照明は明るく、親しみやすい印象。
- 構図：片側にガラスの縦枠、反対側に資料棚を入れ、中央は空ける。小窓でも開発作業席とは違う場所だと分かるようにする。
- 人物との対応：話を前へ進める営業らしい軽快さを出す。豪華な役員室や、正式な役職を連想させる席にはしない。
