# あなた（主人公）

## 基本設定

| 項目 | 設定 |
|---|---|
| 表示名 | あなた／主人公 |
| 元シナリオの話者ID | `player` |
| 所属 | 自社側。株式会社コウカンゲン |
| 立場 | 未経験で入社したエンジニア。折原に経験豊富な担当として客先へ送り込まれる |
| 当面の望み | 目の前の仕事を無事に終えること |

## 原稿から読み取れる人物像

常識的な感覚を持つが、技術も現場の事情もまだよく分かっていない。未経験と伝えたはずなのに「経験5年」として紹介され、困惑したまま仕事が始まる。

分からないことは真壁に質問する。ただし、質問すれば必ず助けてもらえるわけではない。テストや状態、ログを手がかりに修正し、少しずつ経験を積んでいく。

折原の説明や現場の判断に違和感を覚える。部長の自己承認の依頼にも「本当につくってよかったのでしょうか」と疑問を持つ。一方で、周囲を正論で説き伏せるほどの立場や自信はまだない。

## 話し方と反応

- 対外的には丁寧。「未経験ってお伝えしましたよね…？」「どの辺を見たらいいですか？」と確認する。
- 心の声では率直に状況を疑う。口に出せない不安や、折原への観察を短く挟む。
- 「……」「…いきなり即戦力扱いですか！？」のように、間と素朴な反応で笑いを作る。
- 状況が進むにつれ問題に気づけるようになるが、急に何でも知っている人物にはしない。

## 他の人物との関係

- 折原：仕事を持ってくる営業。自分の経験を盛られ、毎回巻き込まれる。
- 真壁：技術面で頼りたい先輩。忙しさや諦めも見え、相談をためらうことがある。
- 佐伯：発注側の依頼・報告の相手。要求の勢いに押されながら、何を求められているのか確認する。
- 三田：業務の事情を知る発注側の担当者。技術だけでは判断できないルールに気づくきっかけになる。

## 報告ドリルでの会話方針

最初は依頼の意味も十分につかめていない。調査で得た事実を自分の言葉にし、相手の問いへ答えられるようになる過程を描く。

プレイヤーがまだ調べていない情報を、主人公だけが知っている状態にしない。失敗時は「もっと調べればよかった」だけでなく、何を聞かれていたのかに気づく余地を残す。

## 部屋の特徴（Web会議の背景）

客先の開発作業スペースの一角。まだ自分の居場所になりきっていない、簡素な席まわりにする。

- 壁・家具：淡いグレーの壁、低い布張りのパーティション、明るい木目の机。奥に共用の棚が少し見える。
- 小物：無地のノート、ペン立て、貸与された備品の箱。持ち込んだ私物は少なく、整えたばかりの印象。
- 色・光：白と薄い木目を中心に、窓から柔らかい昼光。人物の表情を暗くしない。
- 構図：中央の頭・肩まわりは壁面として空け、棚や備品は端へ寄せる。カメラをオンにした小窓でも、背景が人物より目立たないようにする。
- 真壁との描き分け：同じ開発現場の雰囲気を保ちつつ、主人公の席は道具や資料がまだ少ない。
