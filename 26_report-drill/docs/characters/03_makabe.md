# 真壁

## 基本設定

| 項目 | 設定 |
|---|---|
| 表示名 | 先輩・真壁 |
| 元シナリオの話者ID | `lead` |
| 所属 | 自社側。株式会社コウカンゲン |
| 立場 | 主人公の先輩エンジニア。客先で技術的な確認や対応を担う |
| 当面の望み | 現場の問題と自分の仕事を片づけ、今日こそ定時で帰ること |

## 原稿から読み取れる人物像

技術面では常識があり、まずテストを動かして状況を確認する。障害の緊急度を判断し、必要なら発注側へ報告して指示を仰ぐ。動いているから十分という佐伯に対して、リファクタリングも提案する。

ただし、現場の事情にはいろいろ諦めている。主人公から質問されても後回しにするし、不具合の見落としを開発環境の制約で説明してしまうこともある。頼りになる部分と、余裕のなさが同居する。

総点検を求められると表向きは丁寧に引き受け、内心では今の保守体制で対応できるのかを考えている。何でも解決できる万能の先輩ではない。

## 話し方と反応

- 主人公には「まず動かしてみよう」「確認よろしく！」と、短く実務的に話す。
- 発注側には「急ぎ確認します」「状況を確認いたします」と敬語で応じる。
- 疲れや驚きは「くそっ、もうリリース済みか」「……」や心の声に出る。
- 理不尽な操作にも「なるほど通るまでですね」と受け止め、会話の間で諦めを見せる。

## 他の人物との関係

- 主人公：支援する後輩。ただし自分にも仕事があり、いつでも質問に応じられるわけではない。
- 折原：仕事や追加依頼を持ってくる自社の営業。その約束を現場で受け止める側。
- 佐伯：説明や報告をする発注側の担当者。技術的な必要性を伝えるが、費用や納期との間で調整が生じる。
- 三田：業務上の不具合を伝えてくる発注側の担当者。操作の事実を聞き、技術的な状況を確かめる。

## 報告ドリルでの会話方針

自分の調査、会議、作業を持ち、主人公とは別に一日を過ごしている人物として描く。社内チャットには仕事の進み具合や独り言が出る。

質問への返答は時刻と準備状況で変わる。調べた事実と質問が具体的なら話が進むが、丸投げや忙しい時間の質問では進まないこともある。これは報告ドリル側で加わる描写であり、元原稿の支援と余裕のなさを引き継ぐ。

真壁に聞くことを唯一の解決経路にしない。知っている情報にも限界を設け、調べていない事実まで断言させない。

## 部屋の特徴（Web会議の背景）

客先の開発作業スペース。主人公と同じ現場の備品を使いながら、長く対応を続けている席の蓄積を見せる。

- 壁・家具：グレーのパーティション、金属製の資料棚、使い込まれた作業机。端に小さなホワイトボード。
- 小物：背の高さが不ぞろいな技術書、まとめたケーブル、閉じたノートPC、マグカップ。資料は多いが、必要な物には手が届く配置。
- 色・光：青みのあるグレーと落ち着いた木目。天井照明を基本に、作業灯の暖色を少し加える。疲労感を暗さだけで表現しない。
- 構図：右側の参加者小窓に合わせ、片端の資料棚と作業灯で識別できるようにする。中央には頭・肩を置く余白を取る。
- 主人公との描き分け：道具と資料の量で経験と忙しさを出す。散乱したごみや過剰な汚れで人物像を決めつけない。ボードの記載は読めない抽象的な線にする。
