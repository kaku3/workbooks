# 順番のセンス — 文章の順番ドリル

「伝わる順番は、反復で身につく。」説明や文章を4行ずつ並べ替えて、仕事で使う順序の考え方を練習する静的Webアプリです。

## 使い方

1. 「説明の順番」または「文章の順番」を選びます。
2. 初期選択の5問で始めるか、10問に切り替えてから「さらっと5問に挑戦」または「じっくり10問に挑戦」を押します。
3. 4行のカードをドラッグ、または上下ボタンで並べ替えて回答します。問題ごとの正誤は短い全画面エフェクトで表示され、自動で次の問題に進みます。
4. セッション終了後、結果画面で全問の回答と正しい順番を確認し、各問の解説を開けます。

学習記録はブラウザ内に保存されます。直近の成績は日付ごとのグラフで確認できます。同じ日の複数回の挑戦も別々の点として表示します。

## ファイル

- `src/`: GitHub Pagesで公開するサイト
- `src/data/problems.json`: 問題、正解順、解説、難易度
- `docs/ReadMe.md`: 現行仕様、問題データ形式、公開・変更方法

公開する場合は`src/`をサイトの公開ルートに設定してください。このフォルダには専用のデプロイworkflowは含まれていないため、GitHub Pagesを使う場合はホスティング先リポジトリの設定が必要です。詳細は[仕様書](docs/ReadMe.md)を参照してください。
