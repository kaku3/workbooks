# 設計の階層ドリル

設計書を書くときに、文章がどの階層で決める内容かを判断する練習ドリルです。問題文を「要求」「要件」「外部仕様」「詳細設計」の4つに分類します。

## 現在の機能

- `src/data/problems.json`に収録した50問から、5問または10問をランダムに出題
- 分類先ボタンのクリック、または文章カードのドラッグ＆ドロップで回答
- 正誤エフェクトの後に次の問題へ自動で進行。スキップも可能
- 結果画面で正解数、正答率、所要時間、ポイントと各問の解説を表示
- 通常挑戦の完了後に「今日の1問」を解放。同じ日に再挑戦できない
- ポイント、正解数の節目、キャリア段階を`src/data/career.json`で設定
- 学習履歴をブラウザーに保存し、カレンダーと直近10回の正答率グラフに表示
- Facebook、X、LINEの共有リンクとOpen Graph / Xカード用メタデータ

共通の画面遷移、ポイント、今日の1問、学習記録、フッターの仕様は[共通仕様](共通仕様.md)を参照してください。

## 開発と公開

- 編集元: `src/`
- 公開先: `docs/design-layer-drill/`
- 問題: `src/data/problems.json`
- ポイント・キャリア段階: `src/data/career.json`

HTMLからJSONを読み込むため、ローカルではLive ServerなどのWebサーバー経由で`src/index.html`を開きます。アプリを変更した場合は、公開先にも同じファイルを反映してください。
