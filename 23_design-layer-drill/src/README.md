# 問題データの編集

問題は`data/problems.json`の`problems`配列で管理します。現在は50問を収録し、挑戦ごとに全問題から5問または10問をランダムに選びます。

各問題は次の項目を持ちます。

- `id`: 一意の問題ID
- `text`: 分類する文章
- `answer`: `要求`／`要件`／`外部仕様`／`詳細設計`のいずれか
- `reason`: 分類の根拠として結果画面に表示する解説

分類は組織や文脈によって変わります。複数の分類が成り立つ曖昧な文章は避け、問題文と解説で判断の軸が伝わるようにしてください。

## 実装ファイル

- `index.html`: 開始、問題、結果画面と共有フッター
- `style.css`: 画面デザイン、正誤演出、レスポンシブ表示
- `app.js`: 出題、採点、結果、ポイント、今日の1問、ローカル記録、カレンダー、正答率グラフ
- `data/problems.json`: 分類問題と解説
- `data/career.json`: 正解ポイント、正解数の節目ボーナス、キャリア段階
- `assets/ogp.png`: SNS共有用の1200×630px画像。ページのOGP・Xカードのメタデータから参照

ローカルで確認する場合は`src/index.html`をLive ServerなどのローカルWebサーバーで開いてください。問題データを`fetch`で読み込むため、ファイルを直接開く方法では動作しません。

GitHub Pagesの公開先は`docs/design-layer-drill/`です。ソースを変更したら、公開用ファイルも同じ内容に更新してください。Workbooks一覧のリンクとプレビュー画像はルートの`docs/index.html`で管理します。
