# OGP画像の生成記録

生成手段：組み込み image_gen。保存先：`src/assets/ogp.png`、公開用：`docs/design-block-drill/assets/ogp.png`。出力実寸：1732 × 908px。

使用プロンプト（原文）：

```text
Create a polished Japanese social sharing OGP banner for an existing browser learning game. Use case ads-marketing. Output landscape PNG exactly 1200 x 630 pixels (1.905:1). Game name exact text: 「設計ブロックドリル」. Supporting tagline exact text: 「つないで、動かして、設計を身につける」. Small eyebrow exact text: 「WORKBOOKS / DESIGN GAME」. Existing visual identity: dark navy blue background #0c1929 with subtly purple glass panels #2c2039, restrained cyan and lavender outlines, near-future engineering UI, clean modern Japanese sans-serif typography. Large legible title and tagline with spacious hierarchy, safe margins at least 60px. Lower/right area shows a small elegant tilted workflow canvas of connected rectangular blocks, routing cyan success paths and soft orange failure paths, plus a compact row of light mission test cards with circle and cross status marks. Workflow blocks suggest inventory/payment/shipping and approvals, but avoid unnecessary small text. Communicate arranging blocks, running tests and improving software design. Sophisticated flat UI artwork, no people, no photos, no device mockup, no pixel font, no invented logos, no extra text. High contrast and readable as a small link preview. Background opaque.
```

指定サイズとは異なる実寸で生成されたため、メタタグの幅・高さには実寸を記載。
