# 初級：決済を飛ばす注文フロー

ID：`order-basics`

ストーリー：第1章01-01。開始・クリア会話は [第1章原稿](../story/01_order.md)。配置は固定（ドラッグなし）、カードと接続の編集は可。初期設計・テストは既存実装を維持する。

## 狙い・初期の欠陥

4ブロックに絞り、在庫確保から決済を飛ばして出荷へ進む接続を渡す。さらに在庫確保の失敗先を未接続にする。正常注文は出荷条件不足、在庫不足は未接続による荷物停止で失敗し、初期状態では両ケースとも通らない。処理同士の依存関係と成功・失敗分岐を接続で表す練習とする。

## 修正例と確認

在庫確保の成功先を決済へ、失敗先を在庫不足へ変更する。通常注文の決済・出荷が成立し、在庫不足時は注文を在庫不足状態にして決済と出荷を行わないことを2ケースで確認する。接続2箇所の修正で、初めての操作練習にする。
