# 総合：注文システムの設計修正

ID：`order-system`

ストーリー：第1章01-04。開始・クリア会話は [第1章原稿](../story/01_order.md)。配置は固定（ドラッグなし）、カードと接続の編集は可。初期設計・テストは既存実装を維持する。

## 初期の欠陥

- 在庫確保の成功先が出荷に接続され、決済を飛ばす。
- 後処理の先頭がキャンセル確定となり、引当解除・返金の前に失敗する。
- キャンセル失敗ブロックが、確認なしの完了通知へ接続されている。

初期状態では7件中TC-02だけが成功する。通常系にも修正が必要で、一箇所の通知修正だけでは終わらない。

## 修正例と確認

在庫確保→決済→出荷、後処理は引当解除→返金→キャンセル確定とし、失敗経路を通知へ進めない。通知前の成功確認による別解も受理する。全7ケースで回帰を確認する。
