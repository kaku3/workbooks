# 上級：共有在庫と出荷の確定点

ID：`shared-stock`

ストーリー：第1章01-03。開始・クリア会話は [第1章原稿](../story/01_order.md)。配置は固定（ドラッグなし）、カードと接続の編集は可。初期設計・テストは既存実装を維持する。

## 狙い・初期の欠陥

- 在庫確保の失敗先が決済につながり、在庫不足状態が記録されない。
- 決済ブロックが出荷指示→決済の順になっている。
- キャンセル後処理に返金がなく、決済済み注文のキャンセルを確定できない。
- キャンセル失敗が完了通知へつながっている。

初期状態は全7ケースが失敗する。FIFOでの複数注文・在庫不足と、出荷確定後の取消拒否・二重要求を合わせて検証する。厳密な並列競合の問題にはしない。

## 修正例と確認

在庫不足を記録する失敗先へ戻し、決済ブロックは決済だけにする。出荷は次のブロックで行う。後処理へ返金を追加して引当解除→返金→確定の順にし、失敗時の誤通知を防ぐ。全ケースの期待値と副作用件数が一致することを確認する。
