## 設定とトーン

プレイヤーは架空の「株式会社コウカンゲン」に入社した未経験エンジニア。営業の勢いで経験豊富な担当として客先へ送られる。腕前は修正を重ねて周囲に認められていく。会社・人物・事件はすべて創作。実在企業の名称、報道、疑惑は会話へ持ち込まない。

## 会話データ規約

登場人物はイベント開始時に全員を出さず、各自の初発言で1人ずつ表示する。発言済みの人物は残し、現在の話者だけを最前面で強調する。会話文字はPCで約24.7px、スマホで約20.7pxとする。

人物同士は肩が少し重なる間隔で並べ、発言中の人物をz-indexで最前面にする。立ち絵は大きめに表示し、へそ付近より下を会話枠の後ろへ隠す。スマホでは枠との重なりを浅くして顔が隠れないようにする。

立ち絵の背景透過版は `src/assets/*-transparent.png`。元画像は同じ場所の接尾辞なしPNGとして保持し、会話画面は透過版を参照する。透過版は1024×1536のRGBA画像で、`docs/tmp/assets/` にも同期する。

会話ウィンドウの上に、そのイベントに登場する人物を発言順で全員並べる。立ち絵はメッセージ枠の上にはみ出し、発言中の人物だけ明るく少し持ち上げる。`src/assets/01_player.png`?`02_orihara.png`?`03_makabe.png`?`04_saeki.png`?`05_mita.png` を左からplayer・sales・lead・client・accountantの5列スプライトとして使う。メッセージ枠は最大980pxに広げ、下部に送り操作を置く。狭い画面では人物幅を縮める。画像の複製先は `docs/tmp/assets/`。


本文はタイプライター表示する。`**今中に直せますか？！**` のように囲むと大きな太字とアクセント色で強調できる。会話セル内の `<br>`（`<br />` も可）は改行として表示する。それ以外のHTMLは解釈しない。表示途中の「全文表示」で文字送りを完了し、その後の「次へ／閉じる」で会話を進める。スキップは文字送りも停止する。「動きを減らす」設定では最初から全文表示する。

改行を入れる場合も、Markdownの表では1発言を1行に記載する。強調の途中にも改行を入れられる。

```markdown
| lead | まず動かしてみよう。<br>**結果を見て、<br>原因を考えよう！** |
```

原稿を編集したら `node 25_desgin-block-drill/scripts/build-story.mjs` で再生成し、`src/story-data.mjs` を `docs/design-block-drill/story-data.mjs` に同期する。

イベントIDは `{stageId}.intro` と `{stageId}.clear`。イベントは `id`、`stageId`、`drillId`、`timing`（intro/clear）、`lines`（speakerとtextの配列）、`version` を持つ。各章の表をそのまま配列順に読み込める。話者の表示名は上の辞書から解決する。

開始は2〜4発言を基本とし、01-01はユーザー原稿の5発言を維持する（生成時は開始最大5、クリア最大3）。会話中に処理状態・初期設計を書き換えない。クリア台詞の中に、次問の正解操作列を先出ししない。

会話は、経歴を盛る営業、納期優先のリリース、退職者の頭にしかない仕様、雑な引継ぎや「ついでに」の追加依頼を短く笑う方向。主人公には素朴なツッコミを担当させる。教材の仕様・テストは誠実に公開し、先輩は調査や記録を支える。理不尽な依頼そのものを正解として受け入れる展開にはしない。

## 最小進行仕様

- `?mode=story&drill=order-basics` のようにモードを明示する。既存の `?drill=ID` は開発・自由演習用の直接URLとして維持し、章のロック・会話を強制しない。タイトルの章一覧は第1章のみ初回から表示し、第2章はその章の総合をストーリーでクリアすると表示する。未実装IDを自由演習に公開しない。
- ストーリー開始は01-01。各ステージの**同一設計スナップショットを用いた全ケース一括検証**が全成功した時だけclearとする。個別テストの過去の○を合算しない。途中停止・編集・Resetはクリアにしない。
- 通常は開始会話→問題→全成功結果→次の面へ自動遷移→次の開始会話の順。途中ステージのclear会話は再生しない。開始会話は既読でも、つづきから・再訪時を含めて再生する（スキップ可）。
- 最終ステージ02-04のみ、結果エフェクト終了後にclear会話を再生する。読み終えるかスキップするとタイトルへ戻る。結果エフェクトの3秒またはEscape終了後に遷移・会話を開始する。
- NG時はクリアイベントを出さず、その場で再挑戦する。進行中の設計は保存し、次の問題には引き継がない。
- intro/clearのいずれも「スキップ」で閉じられる。introのスキップは解放状態を変えない。clearのスキップはクリア自体を取り消さない。
- 既読はイベントID＋versionで保存する。最後まで読むかスキップを明示した時に既読にする。開始会話は既読でも再生し、「会話を読む」からも再表示できる。パレットのチュートリアルは既読なら自動再生しない。
- clear済みの再挑戦は可能。解放・クリア記録は重複追加しない。再クリアでも通常は次の面へ進み、最終問題のみ終了会話を再生する。以前のクリア記録と、現在の設計の合否は別に表示する。
- 保存例：`story.v1 = { completedStages: [], seenEvents: [], currentStage: '01-01' }`。自由演習の設計保存とは分離する。保存不能でもそのセッション内では進行できる。
- セーブのない未解放ステージへのstory直リンクは、現在の解放済みステージを案内する。自由演習へ切替えて同じ問題を開くことは可能。タイトル画面の見た目・演出は別資料の検討範囲とする。
