# src/

開発用ファイルとデータを置く場所です。

## 初期実装の考え方

- 問題文・カード・正解配置などの問題固有データは `src/data/` に分離する
- ドラッグ可能なカード、配置先、接続線などはHTML/CSS/JavaScriptで構成する
- 最初から複雑な図を画像のように切り分けず、短いラベルのカードを組み立てる課題から始める
- 配置完了後に、完成例を見せる／重ねる／比較する演出を検討する
- 初版はPC向けとし、マウス／トラックパッドでのドラッグとクリック操作に集中する
- 問題開始時に情報カードをキャンバスへランダム配置し、カード右上の削除ボタンでゴミ箱へ移せるようにする。カードを整理したあと、通る順にカードをクリックして矢印を連続して追加する。接続先が次の始点になる。同じカードの再クリック、またはキャンバスの空白クリックで線の追加を終了でき、線をクリックすると表示される「×」で個別に削除できる
- 左のホワイトボードには資料を付箋で表示する。最初は外部設計1枚＋スコープ外2枚で、末尾の「（ヒントを見る）」を押すたびに追加資料を1枚ずつ開く（必要な情報とスコープ外が順不同で混ざる）。付箋はドラッグで自由に動かせ、開くたびに1点減点する
- `index.html?drill=<問題ID>`（例：`?drill=zukai-payment-auth`）で指定した1問を直接開く。存在しないIDのときは通常の開始画面に案内を出す
- 問題開始時は候補カードをすべてキャンバスにランダム配置する。カードの「×」でゴミ箱へ移動し、キャンバス右下のゴミ箱を開いてカードを確認・復元できる
- カードのグリッド／センター／等間隔吸着、上下・左右中央揃え、矢印キーによる位置調整を用意する
- 回答後は解答と正解例を横並びにして比較する。両図の縦横スクロールと拡大率を同期する
- 図のカード幅を揃え、その図の折り返し行数が最も多いカードの高さに全カードを揃える
- 正誤判定と別に、重なりのなさ・中心整列・等間隔の3項目を各1点、合計3点満点の「図の整いポイント」として表示する。意味のまとまりは自動判定が不安定なため、現時点では採点対象にしない

## 用語

「正しい図を描く練習」だけでなく、「図に必要な情報を見つけ、関係を整理し、図に組み立てる練習」を目的とする。

問題データは`data/problems.json`で管理します。現在は難易度（`easy`／`normal`／`hard`）を付けた50問を収録しています。配置するカードと不要な候補、正解の接続関係、完成例のレイアウト、ヒント、解説を問題ごとに記述します。難しい問題には複数の条件分岐を含めます。配置位置は採点せず、カード選択と矢印の向きを含む接続関係で判定します。複数の正解パターンは`connectionAlternatives`で定義できます。
