# 機能フラグの段階公開

- 問題ID：`feature-flag`
- 直接開く：`src/index.html?drill=feature-flag`
- 難易度：normal
- 出典：`src/data/problems.json`

## 問題文

「機能フラグの段階公開」の見直しにあたり、関係者から集めたメモと設計資料です。今回整理する範囲を考えながら、必要な情報を集めてください。

### 課題

図に載せる情報を見極め、付箋を矢印でつないでください。

## 段階開示資料

左側のホワイトボードに付箋として表示します。最初は外部設計1枚＋スコープ外2枚。「（ヒントを見る）」を押すたびに追加資料を1枚開示し、開くたびに1点減点します。追加資料は必要な情報とスコープ外の情報が混ざっており、開示順は毎回ランダムです。付箋はドラッグで自由に動かせます。

### 最初に表示する3枚

1. 外部設計｜処理概要（外部設計）：新機能を一部の利用者へ公開し、様子を見ながら、対象を広げるか止めるかを決める流れ。
2. 要求メモ（スコープ外）：導入時期は繁忙期を避けたい。
3. 画面仕様メモ（スコープ外）：フラグ管理画面の色は、管理ツールの標準テーマに従う。

### 追加で開示する資料（順不同）

| 資料 | 内容 | 種別 | 根拠になる正解接続 |
|---|---|---|---|
| 要件メモ | 「機能フラグを有効化」が終わったら、「限定利用者へ公開」に移る。 | 要件・要求 | 機能フラグを有効化 → 限定利用者へ公開 |
| 外部設計｜処理順序 | 「限定利用者へ公開」を行った後に、「利用状況を監視」へ進む。 | 外部設計 | 限定利用者へ公開 → 利用状況を監視 |
| 要求メモ | 「利用状況を監視」が終わったら、「問題の有無を判定」に移る。 | 要件・要求 | 利用状況を監視 → 問題の有無を判定 |
| 外部設計｜分岐の扱い | 「問題の有無を判定」の後は、状況によって「対象範囲を拡大」／「問題時に機能を停止」に分かれる。 | 外部設計 | 問題の有無を判定 → 対象範囲を拡大<br>問題の有無を判定 → 問題時に機能を停止 |
| 設定メモ | APIのタイムアウトは設定ファイルで管理する。 | スコープ外 | —（図に含めない） |
| 共通デザインメモ | エラー表示の色は共通スタイルに合わせる。 | スコープ外 | —（図に含めない） |

## ヒント

公開後の状態を見て、次の対応を決めます。問題がない場合と、問題が見つかった場合の行き先を考えましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `feature-flag-n1` | 必要 | 機能フラグを有効化 |
| `feature-flag-n2` | 必要 | 限定利用者へ公開 |
| `feature-flag-n3` | 必要 | 利用状況を監視 |
| `feature-flag-n4` | 必要 | 問題の有無を判定 |
| `feature-flag-n5` | 必要 | 対象範囲を拡大 |
| `feature-flag-n6` | 必要 | 問題時に機能を停止 |
| `feature-flag-x1` | 余分・参考 | フラグ管理画面の色 |

## グループ

- **限定公開と監視**：`feature-flag-n1`, `feature-flag-n2`, `feature-flag-n3`, `feature-flag-n4`
- **判定後の操作**：`feature-flag-n5`, `feature-flag-n6`

## 正解の接続

- `feature-flag-n1` → `feature-flag-n2`
- `feature-flag-n2` → `feature-flag-n3`
- `feature-flag-n3` → `feature-flag-n4`
- `feature-flag-n4` → `feature-flag-n5`
- `feature-flag-n4` → `feature-flag-n6`

## 解説

この図では、機能フラグを有効化 → 限定利用者へ公開 → 利用状況を監視 → 問題の有無を判定 → 対象範囲を拡大 → 問題時に機能を停止の関係を整理します。監視結果に応じて拡大または停止します。「フラグ管理画面の色」は今回の流れに含めません。
