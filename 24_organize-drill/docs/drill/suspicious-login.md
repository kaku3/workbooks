# 不審なログインの確認

- 問題ID：`suspicious-login`
- 直接開く：`src/index.html?drill=suspicious-login`
- 難易度：normal
- 出典：`src/data/problems.json`

## 要求仕様

通常と違うログインに追加認証を求め、本人を確認できない場合はロックして本人に知らせたい。 今回の図の対象：通常と異なるログインを検知したとき、追加の認証結果に応じて、許可するか一時的にロックするかを決める流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 通常と異なるログインを検知した利用者には、追加の認証を求める。（内部種別：要件・要求／根拠：通常と異なるログインを検知 → 追加認証を要求）
2. 許可の判断に使う結果は、要求した追加認証に対する回答で確認する。（内部種別：要件・要求／根拠：追加認証を要求 → 認証結果を確認）
3. ログイン画面の背景は、追加認証の案内文が読みやすい画像にしたい。（内部種別：スコープ外／根拠：対象外）

## ヒント

通常と異なるログインでは、認証の結果によって許可するか止めるかが変わります。判断の後を見てみましょう。

## 解説

この図では、通常と異なるログインを検知 → 追加認証を要求 → 認証結果を確認 → ログインを許可 → アカウントを一時ロック → 本人へ通知の関係を整理します。追加認証の成功・失敗で次の処理を分けます。「ログイン画面の背景」は今回の流れに含めません。
