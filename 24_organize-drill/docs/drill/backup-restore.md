# バックアップからの復旧

- 問題ID：`backup-restore`
- 難易度：normal
- 出典：`src/data/problems.json`

## 問題文

「バックアップからの復旧」の設計見直しで出た記述です。

### 課題

図に載せる情報を見極め、付箋を矢印でつないでください。

## 資料の断片（現行データ）

### 要求仕様

- 「データを復元」の後に「復元結果を検証」を行いたい

### 要件

- 応答時間は3秒以内
- 「バックアップ媒体の外観」は担当者間で認識が異なる

### 外部設計

- 画面文言は後日確定
- 「復元結果を検証」の次に「依頼者へ完了を通知」を行う
- 「対象データと時点を確認」の次に「バックアップを選択」を行う

### 詳細設計（現行データ）

- 「復旧依頼を受け付ける」完了後に「対象データと時点を確認」を呼び出す
- 「バックアップを選択」完了後に「データを復元」を呼び出す

## ヒント

復元を始める前に、何をいつの状態に戻すのか確かめる必要があります。復元した後の確認まで含めましょう。

## グループ

- **依頼と復元準備**：`backup-restore-n1`, `backup-restore-n2`, `backup-restore-n3`

## 解説

この図では、復旧依頼を受け付ける → 対象データと時点を確認 → バックアップを選択 → データを復元 → 復元結果を検証 → 依頼者へ完了を通知の関係を整理します。対象と復元時点を確認してから復元します。「バックアップ媒体の外観」は今回の流れに含めません。
