# バックアップからの復旧

- 問題ID：`backup-restore`
- 直接開く：`src/index.html?drill=backup-restore`
- 難易度：normal
- 出典：`src/data/problems.json`

## 問題文

「バックアップからの復旧」の見直しにあたり、関係者から集めたメモと設計資料です。今回整理する範囲を考えながら、必要な情報を集めてください。

### 課題

図に載せる情報を見極め、付箋を矢印でつないでください。

## 段階開示資料

左側のホワイトボードに付箋として表示します。最初は外部設計1枚＋スコープ外2枚。「（ヒントを見る）」を押すたびに追加資料を1枚開示し、開くたびに1点減点します。追加資料は必要な情報とスコープ外の情報が混ざっており、開示順は毎回ランダムです。付箋はドラッグで自由に動かせます。

### 最初に表示する3枚

1. 外部設計｜処理概要（外部設計）：復旧の依頼を受けて、バックアップからデータを戻し、依頼者へ完了を伝えるまでの流れ。
2. 備品メモ（スコープ外）：バックアップ媒体の外観は、保管庫の運用ルールに従う。
3. 帳票メモ（スコープ外）：帳票レイアウトは別紙を参照する。

## ヒント

復元を始める前に、何をいつの状態に戻すのか確かめる必要があります。復元した後の確認まで含めましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `backup-restore-n1` | 必要 | 復旧依頼を受け付ける |
| `backup-restore-n2` | 必要 | 対象データと時点を確認 |
| `backup-restore-n3` | 必要 | バックアップを選択 |
| `backup-restore-n4` | 必要 | データを復元 |
| `backup-restore-n5` | 必要 | 復元結果を検証 |
| `backup-restore-n6` | 必要 | 依頼者へ完了を通知 |
| `backup-restore-x1` | 余分・参考 | バックアップ媒体の外観 |

## グループ

- **依頼と復元準備**：`backup-restore-n1`, `backup-restore-n2`, `backup-restore-n3`
- **復元と確認**：`backup-restore-n4`, `backup-restore-n5`, `backup-restore-n6`

## 正解の接続

- `backup-restore-n1` → `backup-restore-n2`
- `backup-restore-n2` → `backup-restore-n3`
- `backup-restore-n3` → `backup-restore-n4`
- `backup-restore-n4` → `backup-restore-n5`
- `backup-restore-n5` → `backup-restore-n6`

## 解説

この図では、復旧依頼を受け付ける → 対象データと時点を確認 → バックアップを選択 → データを復元 → 復元結果を検証 → 依頼者へ完了を通知の関係を整理します。対象と復元時点を確認してから復元します。「バックアップ媒体の外観」は今回の流れに含めません。
