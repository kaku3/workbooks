# バックアップからの復旧

- 問題ID：`backup-restore`
- 直接開く：`src/index.html?drill=backup-restore`
- 難易度：normal
- 出典：`src/data/problems.json`

## 要求仕様

依頼された時点のデータをバックアップから復元し、結果を確認して完了を知らせたい。 今回の図の対象：復旧の依頼を受けて、バックアップからデータを戻し、依頼者へ完了を伝えるまでの流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 依頼者に、戻したいデータと必要な時点を確認する。（内部種別：要件・要求／根拠：復旧依頼を受け付ける → 対象データと時点を確認）
2. バックアップは、確認した対象と時点に合うものを選ぶ。（内部種別：要件・要求／根拠：対象データと時点を確認 → バックアップを選択）
3. バックアップ媒体の外観で保管世代を見分けられるようにしたい。（内部種別：スコープ外／根拠：対象外）

## ヒント

復元を始める前に、何をいつの状態に戻すのか確かめる必要があります。復元した後の確認まで含めましょう。

## 解説

この図では、復旧依頼を受け付ける → 対象データと時点を確認 → バックアップを選択 → データを復元 → 復元結果を検証 → 依頼者へ完了を通知の関係を整理します。対象と復元時点を確認してから復元します。「バックアップ媒体の外観」は今回の流れに含めません。
