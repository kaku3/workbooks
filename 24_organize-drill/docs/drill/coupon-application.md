# クーポン適用

- 問題ID：`coupon-application`
- 直接開く：`src/index.html?drill=coupon-application`
- 難易度：hard
- 出典：`src/data/problems.json`

## 要求仕様

期限と対象商品の条件を満たすクーポンだけを使えるようにし、使えない場合は理由を表示したい。 今回の図の対象：利用者がクーポンを使うときに、条件を確認して割引を適用する流れ。条件を満たさない場合の扱いも含む。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 入力されたコードのクーポンを特定し、有効期限を調べる。（内部種別：要件・要求／根拠：クーポンコードを入力 → 有効期限を確認）
2. 期限切れなら利用できない理由を出す。有効なクーポンは、購入商品が対象かも確認する。（内部種別：要件・要求／根拠：有効期限を確認 → 対象商品を確認、有効期限を確認 → 利用できない理由を表示）
3. キャンペーンバナーは割引額の文字が読みやすい配色にしたい。（内部種別：スコープ外／根拠：対象外）

### 追加で開示する資料（順不同）

## ヒント

割引には複数の条件がありそうです。確認が一つ終わっただけで適用してよいか、結果による行き先の違いを考えましょう。

## 解説

この図では、クーポンコードを入力 → 有効期限を確認 → 対象商品を確認 → 割引を適用 → 利用できない理由を表示の関係を整理します。期限と対象商品の両方を満たす場合だけ割引します。「キャンペーンバナーの色」は今回の流れに含めません。
