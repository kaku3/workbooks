# 採用選考

- 問題ID：`recruiting`
- 直接開く：`src/index.html?drill=recruiting`
- 難易度：normal
- 出典：`src/data/problems.json`

## 要求仕様

応募者の書類と面接をもとに採用可否を判断し、本人に結果を伝えたい。今回は書類確認を通過した応募を扱う。 今回の図の対象：応募を受けてから、書類の確認と面接を経て、選考結果を伝えるまでの流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 応募受付時に届く書類を、選考の確認対象にする。（内部種別：要件・要求／根拠：応募を受け付ける → 応募書類を確認）
2. 面接担当には、確認を終えた応募書類を渡す。（内部種別：要件・要求／根拠：応募書類を確認 → 面接を実施）
3. 面接室の場所を地図で確認し、受付からの道順も見られるようにしたい。（内部種別：スコープ外／根拠：対象外）

## ヒント

選考の途中までは共通でも、判断後の連絡は同じとは限りません。結果に応じた行き先を考えましょう。

## 解説

この図では、応募を受け付ける → 応募書類を確認 → 面接を実施 → 採用可否を判定 → 採用を通知 → 不採用を通知の関係を整理します。判定後の結果連絡を採用・不採用に分けます。「面接室の場所」は今回の流れに含めません。
