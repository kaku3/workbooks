# 採用選考

- 問題ID：`recruiting`
- 直接開く：`src/index.html?drill=recruiting`
- 難易度：normal
- 出典：`src/data/problems.json`

## 問題文

「採用選考」の見直しにあたり、関係者から集めたメモと設計資料です。今回整理する範囲を考えながら、必要な情報を集めてください。

### 課題

関係する付箋を選び、情報のつながりを矢印で整理してください。

## 段階開示資料

左側のホワイトボードに付箋として表示します。最初は外部設計1枚＋スコープ外2枚。「（ヒントを見る）」を押すたびに追加資料を1枚開示し、開くたびに1点減点します。追加資料は必要な情報とスコープ外の情報が混ざっており、開示順は毎回ランダムです。付箋はドラッグで自由に動かせます。

### 最初に表示する3枚

1. 外部設計｜処理概要（外部設計）：応募を受けてから、書類の確認と面接を経て、選考結果を伝えるまでの流れ。
2. 設定メモ（スコープ外）：APIのタイムアウトは設定ファイルで管理する。
3. 総務メモ（スコープ外）：面接室の場所は、フロア案内に従う。

## ヒント

選考の途中までは共通でも、判断後の連絡は同じとは限りません。結果に応じた行き先を考えましょう。

## 解説

この図では、応募を受け付ける → 応募書類を確認 → 面接を実施 → 採用可否を判定 → 採用を通知 → 不採用を通知の関係を整理します。判定後の結果連絡を採用・不採用に分けます。「面接室の場所」は今回の流れに含めません。
