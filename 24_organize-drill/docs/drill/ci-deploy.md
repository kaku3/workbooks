# テストから本番公開

- 問題ID：`ci-deploy`
- 難易度：hard
- 出典：`src/data/problems.json`

## 問題文

「テストから本番公開」について集めたメモです。

### 課題

図に必要な付箋を選び、処理の流れを矢印でつないでください。

## 資料の断片（現行データ）

### 要求仕様

- 「公開後のヘルスチェック」の結果で「公開完了を通知」／「前バージョンへ戻す」を使い分けたい
- 「テスト結果を判定」の結果で「本番環境へ公開」／「失敗内容を開発者へ通知」を使い分けたい

### 要件

- 「自動テストを実行」完了後に「テスト結果を判定」へ進む
- 操作ログは1年間保存
- 「修正して再実行」完了後に「自動テストを実行」へ進む

### 外部設計

- 「本番環境へ公開」の次に「公開後のヘルスチェック」を行う
- 「変更を取り込む」の次に「自動テストを実行」を行う
- エラー表示の色は共通スタイルに合わせる
- 「失敗内容を開発者へ通知」の次に「修正して再実行」を行う

### 詳細設計（現行データ）

- 「自動テストを実行」完了後に「テスト結果を判定」を呼び出す
- 「開発端末の機種名」も論点に挙がったが未決定
- 入力項目の桁数・型はテーブル定義に従う

## ヒント

テスト結果と、公開後の確認は別の判断です。失敗した場合にどこへ戻るかも含めて流れを追いましょう。

## 解説
