# 返品・交換の受付

- 問題ID：`return-exchange`
- 直接開く：`src/index.html?drill=return-exchange`
- 難易度：normal
- 出典：`src/data/problems.json`

## 要求仕様

返品の可否を購入情報から確認し、対象品の返送と返金または交換を受け付けたい。 今回の図の対象：利用者からの返品・交換の申請を受け付け、条件に応じて対応を案内する流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 返品申請に記載された注文を使って、購入時の情報を照合する。（内部種別：要件・要求／根拠：返品を申請 → 購入情報を確認）
2. 返品条件の判定には、確認できた購入日や商品情報を使う。（内部種別：要件・要求／根拠：購入情報を確認 → 返品条件を判定）
3. 返品受付画面では入力欄と説明欄を色でも見分けられるようにしたい。（内部種別：スコープ外／根拠：対象外）

## ヒント

申請内容を確認した後、条件に合う場合と合わない場合で案内が変わります。その後の処理も追ってみましょう。

## 解説

この図では、返品を申請 → 購入情報を確認 → 返品条件を判定 → 返送方法を案内 → 対象外の理由を通知 → 返送品を受領 → 返金または交換を処理の関係を整理します。返品条件の判定後に案内を分岐します。「返品受付画面の配色」は今回の流れに含めません。
