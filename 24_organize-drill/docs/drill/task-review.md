# 作業依頼のレビュー

- 問題ID：`task-review`
- 難易度：normal
- 出典：`src/data/problems.json`

## 問題文

「作業依頼のレビュー」について集めたメモです。

### 課題

図に載せる情報を見極め、付箋を矢印でつないでください。

## 資料の断片（現行データ）

### 要求仕様

- 「依頼フォームの背景色」も論点に挙がったが未決定
- 導入時期は繁忙期を避ける

### 要件

- 「必要情報を確認」完了後に「情報が十分か判定」へ進む
- 応答時間は3秒以内

### 外部設計

- 「担当者へ割り当て」の次に「着手予定を通知」を行う

### 詳細設計（現行データ）

- 「情報が十分か判定」の戻り値で「不足情報を依頼者へ確認」／「担当者へ割り当て」を切り替える
- 「作業依頼を受け付ける」完了後に「必要情報を確認」を呼び出す

## ヒント

依頼内容が十分かどうかで、担当者へ回す前に必要な作業が変わります。判断の後を見比べてみましょう。

## 解説

この図では、作業依頼を受け付ける → 必要情報を確認 → 情報が十分か判定 → 不足情報を依頼者へ確認 → 担当者へ割り当て → 着手予定を通知の関係を整理します。不足情報がある依頼は割り当て前に確認します。「依頼フォームの背景色」は今回の流れに含めません。
