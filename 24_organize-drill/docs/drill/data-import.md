# 顧客データの一括取込

- 問題ID：`data-import`
- 直接開く：`src/index.html?drill=data-import`
- 難易度：normal
- 出典：`src/data/problems.json`

## 要求仕様

顧客CSVを検証し、正常な行を登録して、不備のある行を確認できるようにしたい。今回は列構成が正しいファイルを扱う。 今回の図の対象：CSVで受け取った顧客データを検証し、問題のないものを登録する流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 受け付けたCSVは、まず列構成の検証対象になる。（内部種別：要件・要求／根拠：CSVを受け付ける → 列構成を検証）
2. 列構成が正しいCSVについて、各行の必須項目を調べる。（内部種別：要件・要求／根拠：列構成を検証 → 各行の必須項目を検証）
3. 取込担当者の部署名を一覧に表示し、連絡先を探しやすくしたい。（内部種別：スコープ外／根拠：対象外）

## 解説

この図では、CSVを受け付ける → 列構成を検証 → 各行の必須項目を検証 → 有効行を登録 → 不備行をエラー一覧に出力の関係を整理します。ファイル全体の形式確認と行単位の検証を分けます。「取込担当者の部署名」は今回の流れに含めません。
