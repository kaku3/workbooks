# 注文キャンセルと返金

- 問題ID：`zukai-refund`
- 直接開く：`src/index.html?drill=zukai-refund`
- 難易度：hard
- 出典：`src/data/problems.json`

## 要求仕様

注文のキャンセルを受けて返金可否を確認し、返金結果を管理したい。失敗分は再試行できるようにする。 今回の図の対象：担当者が注文をキャンセルしたあと、返金の可否と決済代行からの結果に応じて対応を進める流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 返金の確認対象は、担当者がキャンセルした注文とする。（内部種別：要件・要求／根拠：担当者が注文をキャンセル → 返金対象か判定）
2. 返金対象の注文だけを決済代行に送る。対象でなければ、その旨を担当者に知らせる。（内部種別：要件・要求／根拠：返金対象か判定 → 決済代行へ返金API、返金対象か判定 → 返金対象外を担当者へ通知）
3. 注文メモは200文字まで入力できるようにし、残り文字数も確認したい。（内部種別：スコープ外／根拠：対象外）

## ヒント

返金できるかどうかの判断と、APIを呼び出した後の結果に注目しましょう。失敗時の対応も忘れずに。
