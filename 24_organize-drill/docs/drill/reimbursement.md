# 出張経費の精算

- 問題ID：`reimbursement`
- 直接開く：`src/index.html?drill=reimbursement`
- 難易度：normal
- 出典：`src/data/problems.json`

## 要求仕様

出張経費を領収書と照合して承認されたものを支払いたい。不備があれば申請者に修正を求める。 今回の図の対象：社員が出張経費を申請し、確認と承認を経て支払うまでの流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 経費申請には、支出を証明する領収書を追加してもらう。（内部種別：要件・要求／根拠：社員が経費を申請 → 領収書を添付）
2. 経理は添付された領収書を使って、申請金額を確認する。（内部種別：要件・要求／根拠：領収書を添付 → 経理が金額を確認）
3. 出張先の観光情報は、移動日程を考える際に見られるようにしたい。（内部種別：スコープ外／根拠：対象外）

### 追加で開示する資料（順不同）

| 資料 | 内容 | 種別 | 根拠になる正解接続 |
|---|---|---|---|
| reimbursement-doc-04 | 金額や証憑に不備があれば差し戻す。不備がなければ上長の承認対象にする。 | 要件・要求 | 経理が金額を確認 → 不備を差し戻す<br>経理が金額を確認 → 上長が承認 |
| reimbursement-doc-05 | 支払いは、上長が承認した経費だけに行う。 | 要件・要求 | 上長が承認 → 経費を支払う |

## ヒント

金額の確認で不備が見つかった場合、承認へ進む前に対応が必要です。確認結果の違いに注目しましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `reimbursement-n1` | 必要 | 社員が経費を申請 |
| `reimbursement-n2` | 必要 | 領収書を添付 |
| `reimbursement-n3` | 必要 | 経理が金額を確認 |

## グループ

- **申請と確認**：`reimbursement-n1`, `reimbursement-n2`, `reimbursement-n3`
- **確認後の処理**：`reimbursement-n4`, `reimbursement-n5`, `reimbursement-n6`

## 正解の接続

- `reimbursement-n1` → `reimbursement-n2`
- `reimbursement-n2` → `reimbursement-n3`
- `reimbursement-n3` → `reimbursement-n4`
- `reimbursement-n3` → `reimbursement-n5`

## 解説

この図では、社員が経費を申請 → 領収書を添付 → 経理が金額を確認 → 不備を差し戻す → 上長が承認 → 経費を支払うの関係を整理します。証憑や金額に不備があれば承認前に差し戻します。「出張先の観光情報」は今回の流れに含めません。
