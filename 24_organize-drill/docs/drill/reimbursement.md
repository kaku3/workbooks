# 出張経費の精算

- 問題ID：`reimbursement`
- 直接開く：`src/index.html?drill=reimbursement`
- 難易度：normal
- 出典：`src/data/problems.json`

## 問題文

「出張経費の精算」の見直しにあたり、関係者から集めたメモと設計資料です。今回整理する範囲を考えながら、必要な情報を集めてください。

### 課題

図に必要な付箋を選び、処理の流れを矢印でつないでください。

## 段階開示資料

左側のホワイトボードに付箋として表示します。最初は外部設計1枚＋スコープ外2枚。「（ヒントを見る）」を押すたびに追加資料を1枚開示し、開くたびに1点減点します。追加資料は必要な情報とスコープ外の情報が混ざっており、開示順は毎回ランダムです。付箋はドラッグで自由に動かせます。

### 最初に表示する3枚

1. 外部設計｜処理概要（外部設計）：社員が出張経費を申請し、確認と承認を経て支払うまでの流れ。
2. 社内報メモ（スコープ外）：出張先の観光情報は、社内報のコラム用に集めている。
3. 研修メモ（スコープ外）：操作研修の資料は別途用意する。

### 追加で開示する資料（順不同）

| 資料 | 内容 | 種別 | 根拠になる正解接続 |
|---|---|---|---|
| 詳細設計｜内部処理 | 「社員が経費を申請」が終わったら、「領収書を添付」に移る。 | 詳細設計 | 社員が経費を申請 → 領収書を添付 |
| 詳細設計｜内部処理 | 「領収書を添付」が終わったら、「経理が金額を確認」に移る。 | 詳細設計 | 領収書を添付 → 経理が金額を確認 |
| 外部設計｜分岐の扱い | 「経理が金額を確認」の結果次第で、行き先（「不備を差し戻す」、「上長が承認」）が決まる。 | 外部設計 | 経理が金額を確認 → 不備を差し戻す<br>経理が金額を確認 → 上長が承認 |
| 外部設計｜処理順序 | 「上長が承認」を行った後に、「経費を支払う」へ進む。 | 外部設計 | 上長が承認 → 経費を支払う |
| 帳票メモ | 帳票レイアウトは別紙を参照する。 | スコープ外 | —（図に含めない） |
| 利用メモ | 同時利用は最大50人を想定している。 | スコープ外 | —（図に含めない） |

## ヒント

金額の確認で不備が見つかった場合、承認へ進む前に対応が必要です。確認結果の違いに注目しましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `reimbursement-n1` | 必要 | 社員が経費を申請 |
| `reimbursement-n2` | 必要 | 領収書を添付 |
| `reimbursement-n3` | 必要 | 経理が金額を確認 |
| `reimbursement-n4` | 必要 | 不備を差し戻す |
| `reimbursement-n5` | 必要 | 上長が承認 |
| `reimbursement-n6` | 必要 | 経費を支払う |
| `reimbursement-x1` | 余分・参考 | 出張先の観光情報 |

## グループ

- **申請と確認**：`reimbursement-n1`, `reimbursement-n2`, `reimbursement-n3`
- **確認後の処理**：`reimbursement-n4`, `reimbursement-n5`, `reimbursement-n6`

## 正解の接続

- `reimbursement-n1` → `reimbursement-n2`
- `reimbursement-n2` → `reimbursement-n3`
- `reimbursement-n3` → `reimbursement-n4`
- `reimbursement-n3` → `reimbursement-n5`
- `reimbursement-n5` → `reimbursement-n6`

## 解説

この図では、社員が経費を申請 → 領収書を添付 → 経理が金額を確認 → 不備を差し戻す → 上長が承認 → 経費を支払うの関係を整理します。証憑や金額に不備があれば承認前に差し戻します。「出張先の観光情報」は今回の流れに含めません。
