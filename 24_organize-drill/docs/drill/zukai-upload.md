# ファイルアップロードと検証

- 問題ID：`zukai-upload`
- 難易度：hard
- 出典：`src/data/problems.json`

## 問題文

「ファイルアップロードと検証」の打ち合わせ後に残った資料です。

### 課題

資料の順番に惑わされず、必要な付箋を選んで図にしてください。

## 資料の断片（現行データ）

### 要求仕様

- 「サイズ上限10MBを確認」の結果で「拡張子がPDFか確認」／「エラーを表示」を使い分けたい
- 「拡張子がPDFか確認」の結果で「ファイルを保存」／「エラーを表示」を使い分けたい

### 要件

- 同時利用は最大50人

### 外部設計

- エラー表示の色は共通スタイルに合わせる
- 「PDFをアップロード」の次に「サイズ上限10MBを確認」を行う

### 詳細設計（現行データ）

- 「ファイルを保存」完了後に「一覧に反映」を呼び出す
- 「サーバーのディスク容量監視」も論点に挙がったが未決定
- APIのタイムアウトは設定ファイルで管理
- 「サイズ上限10MBを確認」完了後に「エラーを表示」を呼び出す

## ヒント

確認項目が複数あります。どれか一つでも条件を満たさない場合、処理はどうなるでしょう？

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `zukai-upload-n1` | 必要 | PDFをアップロード |
| `zukai-upload-n2` | 必要 | サイズ上限10MBを確認 |
| `zukai-upload-n3` | 必要 | 拡張子がPDFか確認 |
| `zukai-upload-n4` | 必要 | ファイルを保存 |
| `zukai-upload-n5` | 必要 | 一覧に反映 |
| `zukai-upload-n6` | 必要 | エラーを表示 |
| `zukai-upload-x1` | 余分・参考 | サーバーのディスク容量監視 |

## グループ

- **アップロードと検証**：`zukai-upload-n1`, `zukai-upload-n2`, `zukai-upload-n3`
- **検証後の結果**：`zukai-upload-n4`, `zukai-upload-n5`, `zukai-upload-n6`

## 解説

この図では、PDFをアップロード → サイズ上限10MBを確認 → 拡張子がPDFか確認 → ファイルを保存 → 一覧に反映 → エラーを表示の関係を整理します。サイズ・形式のどちらかが不適合ならエラーへ進みます。「サーバーのディスク容量監視」は今回の流れに含めません。
