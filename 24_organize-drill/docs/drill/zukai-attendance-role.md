# 勤怠システムの責務分離

- 問題ID：`zukai-attendance-role`
- 直接開く：`src/index.html?drill=zukai-attendance-role`
- 難易度：normal
- 出典：`src/data/problems.json`

## 問題文

「勤怠システムの責務分離」の見直しにあたり、関係者から集めたメモと設計資料です。今回整理する範囲を考えながら、必要な情報を集めてください。

### 課題

関係する付箋を選び、情報のつながりを矢印で整理してください。

## 段階開示資料

左側のホワイトボードに付箋として表示します。最初は外部設計1枚＋スコープ外2枚。「（ヒントを見る）」を押すたびに追加資料を1枚開示し、開くたびに1点減点します。追加資料は必要な情報とスコープ外の情報が混ざっており、開示順は毎回ランダムです。付箋はドラッグで自由に動かせます。

### 最初に表示する3枚

1. 外部設計｜処理概要（外部設計）：勤怠の打刻と休暇の申請を、人事の確認を経て給与計算へ渡すまでの役割分担を整理する。
2. 未決事項（スコープ外）：入力項目の桁数・型はテーブル定義に従う。画面項目の詳細は別途確認する。
3. 現状メモ（スコープ外）：Excelへの二重転記は現在も残っているが、解消は別の課題として扱う。

## 解説

この図では、社員が出退勤を打刻 → システムが勤務時間を算出 → 社員が休暇を申請 → 上長が休暇を承認 → 人事が勤怠を確認 → 給与計算へ勤務データを連携の関係を整理します。社員・上長・システム・人事の担当範囲を意識します。「Excelへの二重転記」「部署ごとの休憩ルール詳細」は今回の流れに含めません。
