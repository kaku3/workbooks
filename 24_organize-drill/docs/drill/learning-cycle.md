# 学びを次につなげる

- 問題ID：`learning-cycle`
- 難易度：easy
- 出典：`src/data/problems.json`

## 問題文

「学びを次につなげる」の設計見直しで出た記述です。

### 課題

図に載せる情報を見極め、付箋を矢印でつないでください。

## 資料の断片（現行データ）

### 要求仕様

- 「次の目標に向けて練習する」を実現したい
- 「できたことと課題を振り返る」を実現したい
- 「身につけたい操作を決める」の後に「操作を練習する」を行いたい

### 要件

- 「振り返りから次の目標を決める」完了後に「次の目標に向けて練習する」へ進む

### 外部設計

- 利用者から見える動き：操作を練習する
- 画面文言は後日確定
- 利用者から見える動き：身につけたい操作を決める
- 「共有フォルダーを整理する」は担当者間で認識が異なる
- 利用者から見える動き：振り返りから次の目標を決める

### 詳細設計（現行データ）

- 「操作を練習する」完了後に「できたことと課題を振り返る」を呼び出す
- 「次の目標に向けて練習する」完了後に「できたことと課題を振り返る」を呼び出す
- 「できたことと課題を振り返る」完了後に「振り返りから次の目標を決める」を呼び出す

## ヒント

練習して終わりではなく、振り返った後に何が起きるかを考えてみましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `set-goal` | 必要 | 身につけたい操作を決める |
| `practice-skill` | 必要 | 操作を練習する |
| `review-progress` | 必要 | できたことと課題を振り返る |
| `choose-next-goal` | 必要 | 振り返りから次の目標を決める |
| `practice-again` | 必要 | 次の目標に向けて練習する |
| `archive-files` | 余分・参考 | 共有フォルダーを整理する |

## グループ

- **練習**：`practice-skill`, `practice-again`
- **振り返りと次の目標**：`review-progress`, `choose-next-goal`

## 正解の接続

- `set-goal` → `practice-skill`
- `practice-skill` → `review-progress`
- `review-progress` → `choose-next-goal`
- `choose-next-goal` → `practice-again`
- `practice-again` → `review-progress`

## 正解例の配置

| 付箋ID | x | y |
|---|---:|---:|
| `set-goal` | 0.13 | 0.5 |
| `practice-skill` | 0.36 | 0.5 |
| `review-progress` | 0.59 | 0.5 |
| `choose-next-goal` | 0.59 | 0.82 |
| `practice-again` | 0.86 | 0.82 |

## 解説

目標を決めて練習し、できたことと課題を振り返ります。その振り返りから次の目標を決めてまた練習する循環です。共有フォルダーの整理はこの学習サイクルには含めません。
