# 学びを次につなげる

- 問題ID：`learning-cycle`
- 直接開く：`src/index.html?drill=learning-cycle`
- 難易度：easy
- 出典：`src/data/problems.json`

## 要求仕様

身につけたい操作を練習し、振り返りを次の練習に生かす習慣を作りたい。 今回の図の対象：新しい操作を身につけるために、練習と振り返りを繰り返しながら目標を更新していく流れを整理する。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 練習する操作は、その回に身につけたいことに合わせて選ぶ。（内部種別：要件・要求／根拠：身につけたい操作を決める → 操作を練習する）
2. できたことと難しかったことは、実際に操作した経験から書き出す。（内部種別：要件・要求／根拠：操作を練習する → できたことと課題を振り返る）
3. 学習資料を探しやすくするため、共有フォルダーを教材の種類別に整理したい。（内部種別：スコープ外／根拠：対象外）

## ヒント

練習して終わりではなく、振り返った後に何が起きるかを考えてみましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `set-goal` | 必要 | 身につけたい操作を決める |
| `practice-skill` | 必要 | 操作を練習する |
| `review-progress` | 必要 | できたことと課題を振り返る |
| `choose-next-goal` | 必要 | 振り返りから次の目標を決める |
| `practice-again` | 必要 | 次の目標に向けて練習する |
| `archive-files` | 余分・参考 | 共有フォルダーを整理する |

## グループ

- **練習**：`practice-skill`, `practice-again`
- **振り返りと次の目標**：`review-progress`, `choose-next-goal`

## 正解の接続

- `set-goal` → `practice-skill`
- `practice-skill` → `review-progress`
- `review-progress` → `choose-next-goal`
- `choose-next-goal` → `practice-again`
- `practice-again` → `review-progress`

## 解説

目標を決めて練習し、できたことと課題を振り返ります。その振り返りから次の目標を決めてまた練習する循環です。共有フォルダーの整理はこの学習サイクルには含めません。
