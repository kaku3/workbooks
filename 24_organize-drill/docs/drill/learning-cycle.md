# 学びを次につなげる

- 問題ID：`learning-cycle`
- 直接開く：`src/index.html?drill=learning-cycle`
- 難易度：easy
- 出典：`src/data/problems.json`

## 問題文

「学びを次につなげる」の見直しにあたり、関係者から集めたメモと設計資料です。今回整理する範囲を考えながら、必要な情報を集めてください。

### 課題

関係する付箋を選び、情報のつながりを矢印で整理してください。

## 段階開示資料

左側のホワイトボードに付箋として表示します。最初は外部設計1枚＋スコープ外2枚。「（ヒントを見る）」を押すたびに追加資料を1枚開示し、開くたびに1点減点します。追加資料は必要な情報とスコープ外の情報が混ざっており、開示順は毎回ランダムです。付箋はドラッグで自由に動かせます。

### 最初に表示する3枚

1. 外部設計｜処理概要（外部設計）：新しい操作を身につけるために、練習と振り返りを繰り返しながら目標を更新していく流れを整理する。
2. 環境メモ（スコープ外）：共有フォルダーを整理する作業は、年度末にまとめて行っている。
3. 要求メモ（スコープ外）：導入時期は繁忙期を避けたい。

### 追加で開示する資料（順不同）

| 資料 | 内容 | 種別 | 根拠になる正解接続 |
|---|---|---|---|
| 要件メモ | 「身につけたい操作を決める」を受けて、「操作を練習する」につなぐ。 | 要件・要求 | 身につけたい操作を決める → 操作を練習する |
| 要求メモ | 「操作を練習する」を受けて、「できたことと課題を振り返る」につなぐ。 | 要件・要求 | 操作を練習する → できたことと課題を振り返る |
| 要件メモ | 「できたことと課題を振り返る」を行った後に、「振り返りから次の目標を決める」へ進む。 | 要件・要求 | できたことと課題を振り返る → 振り返りから次の目標を決める |
| 外部設計｜処理順序 | 「振り返りから次の目標を決める」の次は「次の目標に向けて練習する」を行う。 | 外部設計 | 振り返りから次の目標を決める → 次の目標に向けて練習する |
| 外部設計｜やり直し | 「次の目標に向けて練習する」を終えたら、もう一度「できたことと課題を振り返る」を行う。 | 外部設計 | 次の目標に向けて練習する → できたことと課題を振り返る |
| 非機能メモ | 応答時間は3秒以内を目標とする。性能の検討は別の資料で行う。 | スコープ外 | —（図に含めない） |
| 未決事項 | 入力項目の桁数・型はテーブル定義に従う。画面項目の詳細は別途確認する。 | スコープ外 | —（図に含めない） |

## ヒント

練習して終わりではなく、振り返った後に何が起きるかを考えてみましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `set-goal` | 必要 | 身につけたい操作を決める |
| `practice-skill` | 必要 | 操作を練習する |
| `review-progress` | 必要 | できたことと課題を振り返る |
| `choose-next-goal` | 必要 | 振り返りから次の目標を決める |
| `practice-again` | 必要 | 次の目標に向けて練習する |
| `archive-files` | 余分・参考 | 共有フォルダーを整理する |

## グループ

- **練習**：`practice-skill`, `practice-again`
- **振り返りと次の目標**：`review-progress`, `choose-next-goal`

## 正解の接続

- `set-goal` → `practice-skill`
- `practice-skill` → `review-progress`
- `review-progress` → `choose-next-goal`
- `choose-next-goal` → `practice-again`
- `practice-again` → `review-progress`

## 正解例の配置

| 付箋ID | x | y |
|---|---:|---:|
| `set-goal` | 0.13 | 0.5 |
| `practice-skill` | 0.36 | 0.5 |
| `review-progress` | 0.59 | 0.5 |
| `choose-next-goal` | 0.59 | 0.82 |
| `practice-again` | 0.86 | 0.82 |

## 解説

目標を決めて練習し、できたことと課題を振り返ります。その振り返りから次の目標を決めてまた練習する循環です。共有フォルダーの整理はこの学習サイクルには含めません。
