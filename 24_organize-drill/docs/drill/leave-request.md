# 休暇申請

- 問題ID：`leave-request`
- 直接開く：`src/index.html?drill=leave-request`
- 難易度：hard
- 出典：`src/data/problems.json`

## 要求仕様

休暇日数と上長の判断に基づいて休暇を登録したい。日数の不備や却下を含め、申請者が結果を把握できること。 今回の図の対象：社員の休暇申請を、日数の上限の確認と上長の判断を経て、予定の登録または通知につなげる流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 提出された休暇申請を、申請日数の上限確認の対象にする。（内部種別：要件・要求／根拠：社員が休暇を申請 → 休暇日数の上限を確認）
2. 上限内の申請を上長の確認対象とする。超過している場合は日数の修正を求める。（内部種別：要件・要求／根拠：休暇日数の上限を確認 → 上長が申請を確認、休暇日数の上限を確認 → 申請日数の修正を依頼）
3. 社内カレンダーでは休日と勤務日を文字と色で区別したい。（内部種別：スコープ外／根拠：対象外）

## ヒント

日数の確認と、上長の判断は別のチェックです。どの条件で予定を登録できるのか、結果の違いに注目しましょう。

## 解説

日数が上限を超える場合は申請日数の修正を依頼し、範囲内なら上長確認へ進みます。上長の承認時は休暇予定を登録し、却下時は理由を通知します。どちらの結果も申請者へ知らせます。
