# 休暇申請

- 問題ID：`leave-request`
- 直接開く：`src/index.html?drill=leave-request`
- 難易度：hard
- 出典：`src/data/problems.json`

## 問題文

「休暇申請」の見直しにあたり、関係者から集めたメモと設計資料です。今回整理する範囲を考えながら、必要な情報を集めてください。

### 課題

図に載せる情報を見極め、付箋を矢印でつないでください。

## 段階開示資料

左側のホワイトボードに付箋として表示します。最初は外部設計1枚＋スコープ外2枚。「（ヒントを見る）」を押すたびに追加資料を1枚開示し、開くたびに1点減点します。追加資料は必要な情報とスコープ外の情報が混ざっており、開示順は毎回ランダムです。付箋はドラッグで自由に動かせます。

### 最初に表示する3枚

1. 外部設計｜処理概要（外部設計）：社員の休暇申請を、日数の上限の確認と上長の判断を経て、予定の登録または通知につなげる流れ。
2. 開発標準メモ（スコープ外）：保存先テーブル名は開発標準に従う。
3. 画面仕様メモ（スコープ外）：社内カレンダーの色は、部署ごとの運用に任せている。

## ヒント

日数の確認と、上長の判断は別のチェックです。どの条件で予定を登録できるのか、結果の違いに注目しましょう。

## 解説

日数が上限を超える場合は申請日数の修正を依頼し、範囲内なら上長確認へ進みます。上長の承認時は休暇予定を登録し、却下時は理由を通知します。どちらの結果も申請者へ知らせます。
