# ログインの流れ

- 問題ID：`zukai-login`
- 直接開く：`src/index.html?drill=zukai-login`
- 難易度：hard
- 出典：`src/data/problems.json`

## 要求仕様

利用可能なアカウントの本人だけがホーム画面に入れるようにしたい。停止中と認証失敗では案内を分ける。 今回の図の対象：利用者がログインしてホーム画面に進むまでの流れ。アカウントの状態と認証の結果によって、行き先が変わる。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 入力されたアカウントを使い、まず利用できる状態か調べる。（内部種別：要件・要求／根拠：認証情報を入力 → アカウント状態を確認）
2. 停止中なら利用停止の案内を出し、認証には進めない。利用可能なアカウントだけを本人確認の対象にする。（内部種別：要件・要求／根拠：アカウント状態を確認 → 利用停止を案内、アカウント状態を確認 → システムが認証）
3. ログイン画面の背景画像は、文字の読みやすさを保ちつつ季節ごとに変えたい。（内部種別：スコープ外／根拠：対象外）

## ヒント

認証の結果によって、そのまま利用できる場合と、利用できない場合がありそうです。結果が変わる場所を探してみましょう。

## 解説

アカウント状態の確認では、利用停止中なら案内を表示し、利用可能なら認証へ進みます。認証結果も成功時はホーム画面、失敗時はエラー表示に分岐します。
