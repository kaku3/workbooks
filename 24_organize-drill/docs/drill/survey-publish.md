# アンケート結果の公開

- 問題ID：`survey-publish`
- 直接開く：`src/index.html?drill=survey-publish`
- 難易度：normal
- 出典：`src/data/problems.json`

## 問題文

「アンケート結果の公開」の見直しにあたり、関係者から集めたメモと設計資料です。今回整理する範囲を考えながら、必要な情報を集めてください。

### 課題

資料の順番に惑わされず、必要な付箋を選んで図にしてください。

## 段階開示資料

左側のホワイトボードに付箋として表示します。最初は外部設計1枚＋スコープ外2枚。「（ヒントを見る）」を押すたびに追加資料を1枚開示し、開くたびに1点減点します。追加資料は必要な情報とスコープ外の情報が混ざっており、開示順は毎回ランダムです。付箋はドラッグで自由に動かせます。

### 最初に表示する3枚

1. 外部設計｜処理概要（外部設計）：アンケートの回答期間が終わってから、集計して結果を公開できる状態にするまでの流れ。
2. 利用メモ（スコープ外）：同時利用は最大50人を想定している。
3. 画面仕様メモ（スコープ外）：アンケート画面のデザインは、前回のものを踏襲する。

### 追加で開示する資料（順不同）

| 資料 | 内容 | 種別 | 根拠になる正解接続 |
|---|---|---|---|
| 詳細設計｜内部処理 | 「回答期間を終了」を行った後に、「回答データを集計」へ進む。 | 詳細設計 | 回答期間を終了 → 回答データを集計 |
| 外部設計｜処理順序 | 「回答データを集計」の次は「個人特定の可能性を確認」を行う。 | 外部設計 | 回答データを集計 → 個人特定の可能性を確認 |
| 外部設計｜処理順序 | 「個人特定の可能性を確認」を行った後に、「公開可能か判定」へ進む。 | 外部設計 | 個人特定の可能性を確認 → 公開可能か判定 |
| 外部設計｜分岐の扱い | 「公開可能か判定」の後は、状況によって「集計結果を公開」／「公開不可の箇所を除外」に分かれる。 | 外部設計 | 公開可能か判定 → 集計結果を公開<br>公開可能か判定 → 公開不可の箇所を除外 |
| 外部設計｜処理順序 | 「公開不可の箇所を除外」を受けて、「集計結果を公開」につなぐ。 | 外部設計 | 公開不可の箇所を除外 → 集計結果を公開 |
| 画面仕様メモ | 画面文言は後日確定する。 | スコープ外 | —（図に含めない） |
| 未決事項 | 入力項目の桁数・型はテーブル定義に従う。画面項目の詳細は別途確認する。 | スコープ外 | —（図に含めない） |

## ヒント

集計結果をそのまま公開できるとは限りません。公開できない情報があった場合の扱いを考えてみましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `survey-publish-n1` | 必要 | 回答期間を終了 |
| `survey-publish-n2` | 必要 | 回答データを集計 |
| `survey-publish-n3` | 必要 | 個人特定の可能性を確認 |
| `survey-publish-n4` | 必要 | 公開可能か判定 |
| `survey-publish-n5` | 必要 | 集計結果を公開 |
| `survey-publish-n6` | 必要 | 公開不可の箇所を除外 |
| `survey-publish-x1` | 余分・参考 | アンケート画面のデザイン |

## グループ

- **集計と確認**：`survey-publish-n1`, `survey-publish-n2`, `survey-publish-n3`, `survey-publish-n4`
- **公開処理**：`survey-publish-n5`, `survey-publish-n6`

## 正解の接続

- `survey-publish-n1` → `survey-publish-n2`
- `survey-publish-n2` → `survey-publish-n3`
- `survey-publish-n3` → `survey-publish-n4`
- `survey-publish-n4` → `survey-publish-n5`
- `survey-publish-n4` → `survey-publish-n6`
- `survey-publish-n6` → `survey-publish-n5`

## 解説

この図では、回答期間を終了 → 回答データを集計 → 個人特定の可能性を確認 → 公開可能か判定 → 集計結果を公開 → 公開不可の箇所を除外の関係を整理します。個人が特定される箇所は除外してから公開します。「アンケート画面のデザイン」は今回の流れに含めません。
