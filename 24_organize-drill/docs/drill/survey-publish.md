# アンケート結果の公開

- 問題ID：`survey-publish`
- 直接開く：`src/index.html?drill=survey-publish`
- 難易度：normal
- 出典：`src/data/problems.json`

## 要求仕様

アンケート結果を集計し、個人を特定できる情報を公開しないよう確認したい。 今回の図の対象：アンケートの回答期間が終わってから、集計して結果を公開できる状態にするまでの流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 公開用の集計対象は、回答期間が終了した時点でそろった回答とする。（内部種別：要件・要求／根拠：回答期間を終了 → 回答データを集計）
2. 個人を特定できないかの確認には、集計結果を使う。（内部種別：要件・要求／根拠：回答データを集計 → 個人特定の可能性を確認）
3. アンケート画面は、設問と回答欄の対応が小さな画面でも分かるデザインにしたい。（内部種別：スコープ外／根拠：対象外）

## ヒント

集計結果をそのまま公開できるとは限りません。公開できない情報があった場合の扱いを考えてみましょう。

## 解説

この図では、回答期間を終了 → 回答データを集計 → 個人特定の可能性を確認 → 公開可能か判定 → 集計結果を公開 → 公開不可の箇所を除外の関係を整理します。個人が特定される箇所は除外してから公開します。「アンケート画面のデザイン」は今回の流れに含めません。
