# 在庫不足の補充

- 問題ID：`stock-reorder`
- 直接開く：`src/index.html?drill=stock-reorder`
- 難易度：easy
- 出典：`src/data/problems.json`

## 要求仕様

在庫不足を補充基準で判断し、発注から入荷後の在庫更新まで管理したい。今回は補充が必要な場合を整理する。 今回の図の対象：在庫数が基準を下回った商品を補充し、在庫数に反映するまでの流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 補充の判断には、実際に確認した在庫数を使う。（内部種別：要件・要求／根拠：在庫数を確認 → 補充基準と比較）
2. 補充基準を下回った品目を仕入先への発注対象にする。（内部種別：要件・要求／根拠：補充基準と比較 → 仕入先へ発注）
3. 倉庫の所在地を地図で確認し、納品業者が搬入口まで迷わず来られるようにしたい。（内部種別：スコープ外／根拠：対象外）

## ヒント

在庫を確認した後、すぐに在庫数を書き換えるわけではありません。発注から入荷までの順番を考えましょう。

## 解説

この図では、在庫数を確認 → 補充基準と比較 → 仕入先へ発注 → 入荷を確認 → 在庫数を更新の関係を整理します。在庫確認から発注、入荷後の反映を順に整理します。「倉庫の所在地」は今回の流れに含めません。
