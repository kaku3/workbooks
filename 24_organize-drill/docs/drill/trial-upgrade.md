# 無料試用から有料プランへ

- 問題ID：`trial-upgrade`
- 難易度：normal
- 出典：`src/data/problems.json`

## 問題文

「無料試用から有料プランへ」に関する資料の断片です。

### 課題

関係する付箋を選び、情報のつながりを矢印で整理してください。

## 資料の断片（現行データ）

### 要求仕様

- 「決済を実行」の結果で「有料機能を有効化」／「決済失敗を案内」を使い分けたい

### 要件

- 応答時間は3秒以内

### 外部設計

- 「利用者がプランを選択」の次に「決済を実行」を行う
- 画面文言は後日確定
- 「プラン選択を案内」の次に「利用者がプランを選択」を行う

### 詳細設計（現行データ）

- 参考：料金ページの写真
- 「試用終了が近づく」完了後に「プラン選択を案内」を呼び出す

## ヒント

プランを選ぶことと、有料機能が使えるようになることの間には確認が必要です。決済結果に注目しましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `trial-upgrade-n1` | 必要 | 試用終了が近づく |
| `trial-upgrade-n2` | 必要 | プラン選択を案内 |
| `trial-upgrade-n3` | 必要 | 利用者がプランを選択 |
| `trial-upgrade-n4` | 必要 | 決済を実行 |
| `trial-upgrade-n5` | 必要 | 有料機能を有効化 |
| `trial-upgrade-n6` | 必要 | 決済失敗を案内 |
| `trial-upgrade-x1` | 余分・参考 | 料金ページの写真 |

## グループ

- **プラン選択**：`trial-upgrade-n1`, `trial-upgrade-n2`, `trial-upgrade-n3`
- **決済結果**：`trial-upgrade-n4`, `trial-upgrade-n5`, `trial-upgrade-n6`

## 正解の接続

- `trial-upgrade-n1` → `trial-upgrade-n2`
- `trial-upgrade-n2` → `trial-upgrade-n3`
- `trial-upgrade-n3` → `trial-upgrade-n4`
- `trial-upgrade-n4` → `trial-upgrade-n5`
- `trial-upgrade-n4` → `trial-upgrade-n6`

## 解説

この図では、試用終了が近づく → プラン選択を案内 → 利用者がプランを選択 → 決済を実行 → 有料機能を有効化 → 決済失敗を案内の関係を整理します。決済が完了した場合だけ有料機能を有効にします。「料金ページの写真」は今回の流れに含めません。
