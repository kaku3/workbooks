# 無料試用から有料プランへ

- 問題ID：`trial-upgrade`
- 直接開く：`src/index.html?drill=trial-upgrade`
- 難易度：normal
- 出典：`src/data/problems.json`

## 要求仕様

試用終了前にプランを案内し、利用者の選択と支払いに応じて有料機能を使えるようにしたい。 今回の図の対象：無料試用の終了前に、利用者が有料プランを選んで決済し、使い続けられるようにする流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 試用期間の残りが少なくなった利用者に、プラン選択を案内する。（内部種別：要件・要求／根拠：試用終了が近づく → プラン選択を案内）
2. 利用者は届いた案内を見て、希望する有料プランを選ぶ。（内部種別：要件・要求／根拠：プラン選択を案内 → 利用者がプランを選択）
3. 料金ページの写真は、プラン名の文字に重ならない位置に置きたい。（内部種別：スコープ外／根拠：対象外）

## ヒント

プランを選ぶことと、有料機能が使えるようになることの間には確認が必要です。決済結果に注目しましょう。

## 解説

この図では、試用終了が近づく → プラン選択を案内 → 利用者がプランを選択 → 決済を実行 → 有料機能を有効化 → 決済失敗を案内の関係を整理します。決済が完了した場合だけ有料機能を有効にします。「料金ページの写真」は今回の流れに含めません。
