# 無料試用から有料プランへ

- 問題ID：`trial-upgrade`
- 直接開く：`src/index.html?drill=trial-upgrade`
- 難易度：normal
- 出典：`src/data/problems.json`

## 問題文

「無料試用から有料プランへ」の見直しにあたり、関係者から集めたメモと設計資料です。今回整理する範囲を考えながら、必要な情報を集めてください。

### 課題

関係する付箋を選び、情報のつながりを矢印で整理してください。

## 段階開示資料

左側のホワイトボードに付箋として表示します。最初は外部設計1枚＋スコープ外2枚。「（ヒントを見る）」を押すたびに追加資料を1枚開示し、開くたびに1点減点します。追加資料は必要な情報とスコープ外の情報が混ざっており、開示順は毎回ランダムです。付箋はドラッグで自由に動かせます。

### 最初に表示する3枚

1. 外部設計｜処理概要（外部設計）：無料試用の終了前に、利用者が有料プランを選んで決済し、使い続けられるようにする流れ。
2. 帳票メモ（スコープ外）：帳票レイアウトは別紙を参照する。
3. 広報メモ（スコープ外）：料金ページの写真は、広報が定期的に差し替える。

### 追加で開示する資料（順不同）

| 資料 | 内容 | 種別 | 根拠になる正解接続 |
|---|---|---|---|
| 外部設計｜処理順序 | 「試用終了が近づく」を受けて、「プラン選択を案内」につなぐ。 | 外部設計 | 試用終了が近づく → プラン選択を案内 |
| 要求メモ | 「プラン選択を案内」の次は「利用者がプランを選択」を行う。 | 要件・要求 | プラン選択を案内 → 利用者がプランを選択 |
| 外部設計｜処理順序 | 「利用者がプランを選択」を行った後に、「決済を実行」へ進む。 | 外部設計 | 利用者がプランを選択 → 決済を実行 |
| 外部設計｜分岐の扱い | 「決済を実行」の結果に応じて、「有料機能を有効化」、「決済失敗を案内」のいずれかへ進む。 | 外部設計 | 決済を実行 → 有料機能を有効化<br>決済を実行 → 決済失敗を案内 |
| 要求メモ | 導入時期は繁忙期を避けたい。 | スコープ外 | —（図に含めない） |
| 未決事項 | 入力項目の桁数・型はテーブル定義に従う。画面項目の詳細は別途確認する。 | スコープ外 | —（図に含めない） |

## ヒント

プランを選ぶことと、有料機能が使えるようになることの間には確認が必要です。決済結果に注目しましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `trial-upgrade-n1` | 必要 | 試用終了が近づく |
| `trial-upgrade-n2` | 必要 | プラン選択を案内 |
| `trial-upgrade-n3` | 必要 | 利用者がプランを選択 |
| `trial-upgrade-n4` | 必要 | 決済を実行 |
| `trial-upgrade-n5` | 必要 | 有料機能を有効化 |
| `trial-upgrade-n6` | 必要 | 決済失敗を案内 |
| `trial-upgrade-x1` | 余分・参考 | 料金ページの写真 |

## グループ

- **プラン選択**：`trial-upgrade-n1`, `trial-upgrade-n2`, `trial-upgrade-n3`
- **決済結果**：`trial-upgrade-n4`, `trial-upgrade-n5`, `trial-upgrade-n6`

## 正解の接続

- `trial-upgrade-n1` → `trial-upgrade-n2`
- `trial-upgrade-n2` → `trial-upgrade-n3`
- `trial-upgrade-n3` → `trial-upgrade-n4`
- `trial-upgrade-n4` → `trial-upgrade-n5`
- `trial-upgrade-n4` → `trial-upgrade-n6`

## 解説

この図では、試用終了が近づく → プラン選択を案内 → 利用者がプランを選択 → 決済を実行 → 有料機能を有効化 → 決済失敗を案内の関係を整理します。決済が完了した場合だけ有料機能を有効にします。「料金ページの写真」は今回の流れに含めません。
