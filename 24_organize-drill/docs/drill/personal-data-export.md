# 個人データの開示請求

- 問題ID：`personal-data-export`
- 直接開く：`src/index.html?drill=personal-data-export`
- 難易度：easy
- 出典：`src/data/problems.json`

## 問題文

「個人データの開示請求」の見直しにあたり、関係者から集めたメモと設計資料です。今回整理する範囲を考えながら、必要な情報を集めてください。

### 課題

関係する付箋を選び、情報のつながりを矢印で整理してください。

## 段階開示資料

左側のホワイトボードに付箋として表示します。最初は外部設計1枚＋スコープ外2枚。「（ヒントを見る）」を押すたびに追加資料を1枚開示し、開くたびに1点減点します。追加資料は必要な情報とスコープ外の情報が混ざっており、開示順は毎回ランダムです。付箋はドラッグで自由に動かせます。

### 最初に表示する3枚

1. 外部設計｜処理概要（外部設計）：本人からの開示請求を受け、本人確認のうえでデータを作成し、受け取り方法を案内するまでの流れ。
2. 画面仕様メモ（スコープ外）：画面文言は後日確定する。
3. 運用メモ（スコープ外）：データ保管場所の詳細は、情報管理規程に記載している。

### 追加で開示する資料（順不同）

| 資料 | 内容 | 種別 | 根拠になる正解接続 |
|---|---|---|---|
| 外部設計｜処理順序 | 「開示請求を受け付ける」の次は「本人確認を行う」を行う。 | 外部設計 | 開示請求を受け付ける → 本人確認を行う |
| 外部設計｜処理順序 | 「本人確認を行う」を受けて、「対象データを抽出」につなぐ。 | 外部設計 | 本人確認を行う → 対象データを抽出 |
| 外部設計｜処理順序 | 「対象データを抽出」を行った後に、「データファイルを作成」へ進む。 | 外部設計 | 対象データを抽出 → データファイルを作成 |
| 要件メモ | 「データファイルを作成」を行った後に、「本人へ受取方法を案内」へ進む。 | 要件・要求 | データファイルを作成 → 本人へ受取方法を案内 |
| 要求メモ | 導入時期は繁忙期を避けたい。 | スコープ外 | —（図に含めない） |
| 利用メモ | 同時利用は最大50人を想定している。 | スコープ外 | —（図に含めない） |

## ヒント

個人データを抽出する前に、本人からの請求か確認する必要があります。確認と抽出の順番に注目しましょう。

## 付箋

| ID | 種別 | ラベル |
|---|---|---|
| `personal-data-export-n1` | 必要 | 開示請求を受け付ける |
| `personal-data-export-n2` | 必要 | 本人確認を行う |
| `personal-data-export-n3` | 必要 | 対象データを抽出 |
| `personal-data-export-n4` | 必要 | データファイルを作成 |
| `personal-data-export-n5` | 必要 | 本人へ受取方法を案内 |
| `personal-data-export-x1` | 余分・参考 | データ保管場所の詳細 |

## グループ

- **請求と本人確認**：`personal-data-export-n1`, `personal-data-export-n2`
- **データ準備**：`personal-data-export-n3`, `personal-data-export-n4`, `personal-data-export-n5`

## 正解の接続

- `personal-data-export-n1` → `personal-data-export-n2`
- `personal-data-export-n2` → `personal-data-export-n3`
- `personal-data-export-n3` → `personal-data-export-n4`
- `personal-data-export-n4` → `personal-data-export-n5`

## 解説

この図では、開示請求を受け付ける → 本人確認を行う → 対象データを抽出 → データファイルを作成 → 本人へ受取方法を案内の関係を整理します。本人確認が終わってからデータを抽出します。「データ保管場所の詳細」は今回の流れに含めません。
