# 個人データの開示請求

- 問題ID：`personal-data-export`
- 直接開く：`src/index.html?drill=personal-data-export`
- 難易度：easy
- 出典：`src/data/problems.json`

## 要求仕様

本人からの開示請求に対して個人データをまとめ、安全に受け取れるよう案内したい。 今回の図の対象：本人からの開示請求を受け、本人確認のうえでデータを作成し、受け取り方法を案内するまでの流れ。

### 操作

要求仕様と左側のメモを読み、右側のカードで必要な処理と関係を図にしてください。

## 段階開示資料

左側にはヒアリングメモを本文だけの付箋で表示します。最初は3枚で、判断の根拠も含みます。「（他のメモも見る）」で追加メモをランダムに1枚開示し、1点減点します。付箋は移動・ゴミ箱への整理・復元ができます。復元による再減点はありません。以下の種別と正解接続はレビュー用の内部情報です。

### 最初に表示する3枚

1. 本人確認は、開示請求を出した人を対象に行う。（内部種別：要件・要求／根拠：開示請求を受け付ける → 本人確認を行う）
2. 個人データを抽出できるのは、請求者を本人と確認できた場合だけ。（内部種別：要件・要求／根拠：本人確認を行う → 対象データを抽出）
3. 情報管理者は、個人データの保管場所と管理責任者を台帳で確認したい。（内部種別：スコープ外／根拠：対象外）

### 追加で開示する資料（順不同）

| 資料 | 内容 | 種別 | 根拠になる正解接続 |
|---|---|---|---|
| personal-data-export-doc-04 | 提供するファイルは、開示対象として抽出したデータから作成する。 | 要件・要求 | 対象データを抽出 → データファイルを作成 |
| personal-data-export-doc-05 | 受取方法の案内には、作成済みのデータファイルを受け取れる情報を載せる。 | 要件・要求 | データファイルを作成 → 本人へ受取方法を案内 |

## ヒント

個人データを抽出する前に、本人からの請求か確認する必要があります。確認と抽出の順番に注目しましょう。

## グループ

- **請求と本人確認**：`personal-data-export-n1`, `personal-data-export-n2`
- **データ準備**：`personal-data-export-n3`, `personal-data-export-n4`, `personal-data-export-n5`

## 正解の接続

## 解説

この図では、開示請求を受け付ける → 本人確認を行う → 対象データを抽出 → データファイルを作成 → 本人へ受取方法を案内の関係を整理します。本人確認が終わってからデータを抽出します。「データ保管場所の詳細」は今回の流れに含めません。
